# مصادر وأسلوب أدوات الوسائط

## توليد الصور

- توثيق Puter الرسمي لواجهة `puter.ai.txt2img`: <https://docs.puter.com/AI/txt2img/>
- تستخدم الأداة واجهة Puter من المتصفح دون مفتاح API مضمّن في الموقع. يتطلب ذلك اتصالاً بالإنترنت، وقد يطلب Puter تسجيل دخول المستخدم أو يطبّق حدوداً/رسوماً وفق حسابه وشروط الخدمة. يجب مراجعة السعر والسياسة في حساب Puter قبل الاستخدام المكثف.
- الصورة الناتجة تُدرج كعنصر صورة في المحرر. إذا كانت Data URL تُضغط محلياً عند الإمكان؛ وإذا كانت وصلة مستضافة خارجياً فقد تكون مؤقتة. يُنصح بحفظ نسخة مستقلة ورفعها إلى استضافة المستخدم قبل نشر المقال.

## YouTube

- توثيق YouTube Data API للبحث: <https://developers.google.com/youtube/v3/docs/search/list>
- زر البحث الحالي يفتح صفحة نتائج YouTube باستعلام مشتق من موضوع المقال؛ لا يُجري بحث API ولا يدّعي أن فيديو معين هو الأفضل. يختار المستخدم فيديوهاته بنفسه.
- عند إدراج الفيديو، تُقبل فقط معرّفات بطول وصيغة YouTube المعروفة من رابط موثوق على `youtube.com` أو `youtu.be` أو `youtube-nocookie.com`. لا يُوثق بمعرّف فيديو يخمّنه نموذج اللغة.
- استعمال YouTube Data API مستقبلاً يتطلب إعداد مشروع Google وبيانات اعتماد وحدود الاستخدام المناسبة؛ لم تُضمّن أي مفاتيح في هذه النسخة.
