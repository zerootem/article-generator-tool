# مولّد المقالات

واجهة عربية RTL لإنشاء المقالات وتحرير عناصرها. بُني المشروع تدريجياً على Vite وTypeScript مع الاحتفاظ بواجهة الأداة الحالية وجسر توافق لملفات JavaScript القديمة.

## الميزات الحالية

تدعم نافذة الذكاء الاصطناعي وضع API بمفتاح المستخدم، وPuter بلا مفتاح خاص، وCloudflare Worker عند إعداد عنوانه ومصادقته. خصائص كل مسار تظهر حسب الاختيار، ومجموعات النماذج والمفاتيح قابلة للطي وتعرض حالة وجود المفتاح. لا يوجد مفتاح مشترك أو عنوان خادم AI قديم مضمّن في كود الواجهة.

قوالب المقال والعناوين والكلمات والوسوم وبيانات SEO تستخدم المزود والنموذج النشطين. اختيارات الكلمات الأساسية والثانوية تُمرر إلى البرومبت على نحو طبيعي، دون فرض كثافة معيارية أو الادعاء ببيانات بحث من Google. تُراعي المطالبات نية القارئ والدقة وعدم اختلاق الخبرة أو الإحصاءات أو المصادر.

توليد الصور اختياري عبر Puter، وقد يتطلب حساباً أو رصيداً وفق سياسة Puter. زر YouTube يفتح بحثاً حقيقياً على موضوع المقال ويترك اختيار الفيديو للمستخدم؛ لا يخمّن النموذج معرّفات الفيديو. راجع [`docs/media-tools.md`](docs/media-tools.md) و[`docs/google-seo-principles.md`](docs/google-seo-principles.md).

يتيح المساعد إنشاء محتوى وإدراجه في نهاية المقال أو عند المؤشر أو باستبدال التحديد، وتحسين النص، واقتراح تعديل موضعي للمقال/التحديد مع معاينة قبل التطبيق وسجل تراجع. يدعم محرر العناصر عناوين note/alert القابلة للتخصيص. أزرار الرجوع تعيد إلى المرحلة السابقة داخل نافذة AI والمساعد وBlogger.

## التشغيل والاختبار

يتطلب التشغيل Node.js وnpm. نفّذ `npm ci` ثم `npm run dev` للمعاينة المحلية. `npm test` يشغّل اختبارات المحرر والبرومبتات والوسائط وWorker، و`npm run build` يفحص TypeScript ويبني نسخة Pages داخل `dist/`. في آخر فحص محلي: نجحت 20/20 اختبارات، وبناء Vite، وفحص صياغة ملفات JavaScript القديمة.

لم يُجر اختبار توليد حي عبر Puter أو مزودي API لأن ذلك يتطلب دخولاً/مفتاحاً، ولم يُختبر محرر الهاتف يدوياً في متصفح حقيقي ضمن هذه الجولة. يجب التحقق من ذلك على جهازك قبل إصدار عام.

## بنية المشروع

`index.html` هي بنية الصفحة؛ `src/styles/` أنماط منفصلة؛ `src/main.ts` نقطة دخول TypeScript؛ `src/editor/` منطق نطاقات التحديد؛ `src/prompts/` مطالبات المحتوى؛ `src/ai/` عميل Worker ومساعد المقال وأدوات الوسائط. لا تزال بقية السلوكيات في `public/assets/js/legacy/` وتُنقل تدريجياً. `worker/` يحتوي Cloudflare Worker اختيارياً، مغلقاً افتراضياً حتى تهيئته.

## حفظ المفاتيح والأمان

المفاتيح الشخصية تحفظ محلياً بعد فتح القفل بكلمة مرور، باستخدام AES-GCM؛ عبارة المرور ومفتاح التشفير لا يُرسلان إلى الخادم، ومفتاح التشفير يبقى في ذاكرة الصفحة. هذا يقلل خطر كشف بيانات التخزين الساكنة، لكنه لا يحمي من XSS أو إضافة متصفح خبيثة أو جهاز مخترق. لا تضع أي سر في الواجهة أو GitHub Pages.

مسارات Worker لا تعمل إنتاجياً حتى إعداد Cloudflare Access وWorker Secrets وKV وقيود الاستخدام. التفاصيل في [`worker/README.md`](worker/README.md)، والمراجع الرسمية في [`worker/REFERENCES.md`](worker/REFERENCES.md). لا تُدخل الأسرار في ملفات المستودع.

## النشر

الموقع الحالي المنشور على GitHub Pages لا يتغير بهذه الجولة. التعديلات محفوظة محلياً على فرع تحسينات منفصل، ولا تُرفع إلى `main` إلا بعد موافقتك على إصدار هذه التحسينات ومراجعة اختبارات الهاتف.
