# مولّد المقالات العربي

أداة ويب عربية لإنشاء المقالات وتحرير عناصرها وتحسينها للنشر، مع مساعد SEO وتكامل نشر إلى Blogger. تعمل الواجهة باتجاه RTL، ويمكن فتح المولّد مباشرة أو الوصول إليه من [مركز ModApp للأدوات](https://zerootem.github.io/modapp/).

**الموقع المنشور:** [zerootem.github.io/article-generator-tool](https://zerootem.github.io/article-generator-tool/)

## ما الذي تقدمه الأداة؟

- إنشاء مقالات عربية منظمة، وتحرير أقسامها وعناصرها من محرر بصري.
- تحسين النص واقتراح تعديلات موضعية للمقال أو التحديد، مع معاينة قبل التطبيق وسجل تراجع.
- إعداد العنوان والوصف والكلمات والوسوم وعناصر SEO، مع مطالبات تركز على نية القارئ والدقة والأصالة، وتتجنب اختلاق الإحصاءات والمصادر أو الخبرة.
- إنشاء محتوى مساعد وإدراجه في نهاية المقال أو عند المؤشر أو باستبدال التحديد.
- توليد صور اختياري عبر Puter، والبحث عن فيديوهات YouTube لاختيارها يدوياً.
- النشر إلى Blogger بعد إعداد حساب المدونة والاتصال المطلوب.
- واجهة قابلة للتثبيت من المتصفح كتطبيق ويب؛ التخزين دون اتصال يوفّر غلاف الواجهة، بينما توليد المحتوى والنشر يتطلبان اتصالاً بالخدمات.

## مزودات الذكاء الاصطناعي

تدعم نافذة الذكاء الاصطناعي ثلاثة مسارات: Puter، واستخدام API بمفتاح يقدمه المستخدم، وCloudflare Worker بعد إعداد الخادم والأسرار والحماية. يظهر كل مسار بحسب اختياره. لا يوجد مفتاح مشترك أو عنوان خادم AI قديم مضمّن في الواجهة. قد يتطلب Puter حساباً أو رصيداً حسب شروطه؛ وقد تتطلب مسارات API وWorker إعداداً إضافياً.

## التشغيل والاختبارات

يتطلب التشغيل Node.js وnpm:

```bash
npm ci
npm run dev
```

للتحقق والبناء:

```bash
npm test
npm run build
```

يشغّل `npm test` اختبارات المحرر والبرومبتات والوسائط والتكاملات، وينشئ `npm run build` ملفات GitHub Pages داخل `dist/`. تُدار عملية النشر من GitHub Actions عند تحديث فرع `main`.

## الأمان والبيانات

تُحفظ مفاتيح المستخدم محلياً بعد فتح الخزنة بكلمة مرور، باستخدام AES-GCM. لا تُرسل عبارة المرور أو مفتاح التشفير إلى الخادم، ويبقى مفتاح التشفير في ذاكرة الصفحة. يقلل ذلك خطر كشف بيانات التخزين الساكنة، لكنه لا يحمي من XSS أو إضافة متصفح خبيثة أو جهاز مخترق. لا تضع الأسرار في ملفات الواجهة أو مستودع GitHub.

تظل وظائف Cloudflare Worker غير متاحة إنتاجياً حتى إعداده بالأسرار والحماية وقيود الاستخدام. راجع [`worker/README.md`](worker/README.md) و[`worker/REFERENCES.md`](worker/REFERENCES.md) قبل تفعيله.

## بنية المشروع

- `index.html`: بنية الأداة.
- `src/main.ts` و`src/`: منطق TypeScript والمحرر والذكاء الاصطناعي واللغة وPWA والأنماط.
- `public/assets/js/legacy/`: سلوكيات JavaScript القديمة التي تُنقل تدريجياً إلى وحدات منفصلة.
- `worker/`: هيكل Cloudflare Worker الاختياري.
