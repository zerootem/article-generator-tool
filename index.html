مزوّد API النشط

يُستخدم هذا الاختيار عند تحديد «مزود API». أضف مفتاح المزود من تبويب المزود أدناه.

الخادم الآمن

يرسل المقال إلى Cloudflare Worker المحمي؛ لا يرسل مفتاح المزود إلى المتصفح. هذا الخيار لا يعمل إلا بعد ضبط VITE_WORKER_URL وCloudflare Access وبيانات الأسرار.
